# Dragon Repeller 🐉

A simple role-playing game built with HTML, CSS, and JavaScript as part of the freeCodeCamp JavaScript Algorithms and Data Structures curriculum.

## Features

* Fight different monsters
* Buy health and weapons from the store
* Manage player health, gold, and experience points
* Dynamic game interface using JavaScript DOM manipulation
* Randomized combat mechanics

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Concepts Practiced

* Variables and Data Types
* Functions
* Arrays and Objects
* Conditional Statements
* Loops
* Event Handling
* DOM Manipulation
* Random Number Generation

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## What I Learned

Through this project, I gained hands-on experience with JavaScript fundamentals, updating web page content dynamically, handling user interactions, and building game logic.
